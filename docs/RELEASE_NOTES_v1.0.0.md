# TEMPO v1.0.0

First Windows 64-bit release of TEMPO, a desktop application for microscopy acquisition and cell-motion analysis.

### Included in this release

- Cell and nuclei annotation with shared image reservations, local drafts, and submission for maintainer review.
- Recording processing, contraction traces and measurements, and result export.
- Camera acquisition and XY-stage collection with compatible hardware.
- AU26 V2 electrical stimulation and multi-field pre-pacing.
- Detection and segmentation model training in Colab using reviewed annotations.
